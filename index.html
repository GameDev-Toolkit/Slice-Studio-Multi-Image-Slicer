    Keyboard and mouse

    V H Add a vertical / horizontal guide, under the pointer when it is over the image
    Drag Move a guide; drag it off the image to remove it
    , . Select the previous / next guide
    ← → ↑ ↓ Nudge the selected guide by 1 px, or 10 px with Shift. Pans the view when no guide is selected
    Del Remove the guide under the pointer or the selected one. Double-click does the same
    Esc Cancel a drag, or clear the selection
    Ctrl+Z Undo. Ctrl+Shift+Z or Ctrl+Y to redo
    Ctrl+C Ctrl+V Copy and paste guides between images. Pasting an image adds it to the project
    Wheel Zoom at the pointer. Pinch to zoom on touch screens and most trackpads
    + − Zoom in / out
    0 1 Fit to window / zoom to 100%
    Space+drag Pan. Dragging empty space or the middle mouse button pans too
    [ ] Previous / next image
    P Toggle the tile preview
    Ctrl+S Export ZIP

    On macOS use ⌘ instead of Ctrl.

    File name placeholders

    {name} Source file name without its extension
    {row} {col} Row and column, counted from 1
    {index} Running number within the image, counted from 1, left to right then top to bottom
    {row0} {col0} {index0} The same, counted from 0
    {x} {y} Top-left corner of the tile in the source image, in pixels
    {index:3} Any number can be zero-padded: 007
    / Starts a folder, e.g. {name}/{row}_{col}
